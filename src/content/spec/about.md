## 你好，这里是 ChronoHex

我是 **BBCSLOOK**，喜欢折腾各种零七杂八的东西，也把折腾过程记录在这里。

这个博客主要收录 Linux、网络基础与 HCIA 学习笔记，以及 AI 工具、自建服务和网站开发中的实践记录。文章里既有操作步骤，也有踩过的坑，希望能方便自己回顾，也给遇到类似问题的人一点参考。

内容会随着学习和实践逐步补充。如果发现错误，欢迎指出。

## 关于这个网站

本站基于 [Fuwari](https://github.com/saicaca/fuwari) 主题定制，源代码保存在 [bbcslook-beep/my-website](https://github.com/bbcslook-beep/my-website)。

目前使用 **Astro 7、Svelte 5 和 Tailwind CSS 4**，构建环境统一为 **Node.js 24 LTS 与 pnpm 10**。页面提前生成为静态文件，通过 Cloudflare Pages、Vercel 和服务器线路提供访问；更新经过检查与预览验证后，再发布到主分支并自动部署。

这里也保留了一些我喜欢的小功能：

- **站内搜索**：由 Pagefind 提供，可以检索文章内容。
- **阅读设置**：支持明暗模式、自定义主题色、文章目录和代码复制。
- **图片查看**：点击文章图片可以放大；背景加载完成后，双击页面非交互区域可进入赏图模式，按 Esc 或点击退出区域返回。
- **线路切换**：侧边栏展示不同线路的连通情况，访问不顺畅时可以尝试切换。
- **评论交流**：文章下方通过 Giscus 接入 GitHub Discussions。

感谢 Fuwari 及相关开源项目的作者，也感谢提供建议和反馈的读者。

## 隐私与外部服务

博客本身不提供独立账户系统。明暗模式、主题色等偏好保存在你的浏览器本地，用于下次访问时恢复设置。

本站使用自建 **Umami** 进行访问统计，帮助了解文章的访问情况；评论由 **Giscus / GitHub Discussions** 提供，评论内容托管在 GitHub。页面中的外部头像、背景图片及线路检测也会向相应服务发起网络请求。

这些服务与博客静态页面分别运行，访问它们时适用各自的服务规则。你可以通过浏览器设置或扩展管理本地存储与外部请求。
